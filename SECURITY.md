# Security policy

## Supported versions

Only the latest revision on the default branch is maintained.

## Reporting a vulnerability

Please use GitHub's **Private vulnerability reporting** feature for this repository. Do not open a public issue containing exploit details, secrets, personal data, or confidential design information.

Include:

- affected file and revision;
- minimal reproduction steps;
- expected and observed behavior;
- potential impact; and
- any proposed mitigation.

You should receive an acknowledgement within seven days. This educational repository does not operate a hosted service and does not accept sensitive design inputs.

## Scope

Reports about the public RTL, testbench, scripts, workflow configuration, or dependency use are in scope. Historical portfolio metrics are documentation claims and are not production service data.
